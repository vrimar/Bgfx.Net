## 3rd-party code bundled in the upstream submodules

below inventories every one of those folders and the license each ships, regenerated by
`build/audit-3rdparty-licenses.sh` on each submodule bump; `--check` fails when the table
no longer matches the submodules. It covers the whole `3rdparty/` tree, which is a
superset of what ends up linked into `bgfx-shared-lib` and the `shaderc`, `texturec` and
`geometryc` tools — examples- and tests-only components are listed too. Several entries
